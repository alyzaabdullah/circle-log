# Circle Log

**A practice log between social-skills sessions.** Built for Autisme sans limites, a Montréal autism organization.

▶ **Try it:** https://alyzaabdullah.github.io/circle-log/ (works on a phone; French first, with an English toggle)

Between sessions of a group social-skills program, participants practise what they learned in real life. Circle Log lets them note each practice in about a minute: which skill, with whom, how it went. They can also set a goal and ask for a call partner. Before the next session, facilitators see who practised, everyone's goals and partner requests, and can pair people for calls.

## This version
This is the **facilitator test version**. It starts empty, like a new group. Facilitators add participants themselves (fictional names only), and each participant gets a QR code to open their own view. A walkthrough runs on first launch, and the test tools let one person try both the facilitator and the participant side.

## Privacy
- Everything is stored **only on this device**. Nothing is sent anywhere: the page blocks all network connections and has no external scripts or fonts.
- No accounts. Use fictional data only.
- A real pilot would add a secure backend hosted in Canada, with privacy review before any real participant data is used.
